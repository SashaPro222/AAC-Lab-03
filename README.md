## Цель

Понять, как числа и текст представляются в памяти в виде байтов, порядок байтов и кодировка UTF-8, и почему для интерпретации байтов нужны правила.

## 1. Представление числа в байтах


 1 -01-00-00-00 
 256-  00-01-00-00 
 65536 - 00-00-01-00 

Каждый следующий «разряд» — это умножение на 256 /на 2⁸, поэтому единица сдвигается на один байт влево.

## 2. Порядок байтов

- `BitConverter.IsLittleEndian` → *True*
- Число `305419896`
- Hex-представление: `0x12345678`
- Байты: `78-56-34-12`

При little-endian переворачивается порядок хранения байтов в памяти.

## 3. Текст и UTF-8

`ABC`  3,3,`41-42-43`
`Привет`  6, 12,`D0-9F-D1-80-D0-B8-D0-B2-D0-B5-D1-82` 

латинские буквы в UTF-8 весят меньше киррилических. Поэтому количество символов и количество байтов отличается. 

## 4. Английская и русская буква

- `A`(англ)  `41`
- `А`(рус)  `D0-90`

Символы по разному обозначаются в Unicode, поэтому их значения в байтах отличаются

## 5. Обратное преобразование

## Контрольные вопросы

1. *Что такое байт и сколько бит содержит один байт?*
   Байт — минимальная адресуемая единица памяти. Один байт содержит 8 бит и может хранить значение от 0 до 255.

2. *Почему int занимает несколько байтов?*
   `int` занимает 4 байта. Такой размер позволяет хранить примерно 4 млрд чисел. Одного байта для типичных вычислений бывает недостаточно.

3. *Что показывает BitConverter.GetBytes()?*
   Возвращает массив байтов, в котором число записано так, как оно лежит в памяти.

4. *Что означает BitConverter.IsLittleEndian?*
   `True` означает, что последний байт числа хранится в памяти первым

5. *Почему порядок байтов может отличаться от привычной записи числа?*
 Процессор может хранить последний байт первым (little-endian). Это работа архитектуры 

6. *Почему количество символов строки не всегда равно количеству байтов?*
   В UTF-8 разные символы занимают разное число байтов: латиница — 1, кириллица — 2.

7. *Что делает Encoding.UTF8.GetBytes()?*
   Преобразует строку в массив байтов.

8. *Зачем для обратного преобразования текста используется Encoding.UTF8.GetString()?*
   Чтобы программа знала по каким правилам собирать символы из байтов.

9. *Почему одни и те же байты могут интерпретироваться по-разному? 
   Байты сами по себе не содержат смысла. Смысл появляется, когда программа применяет к ним правило.

10. *Чем представление числа в памяти отличается от представления текста?*
    Число хранится в фиксированном двоичном формате. Текст хранится как последовательность байтов по правилам кодировки.
